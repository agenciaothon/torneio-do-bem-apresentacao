# Torneio do Bem — Apresentação

Apresentação institucional com 27 slides, animações e navegação por teclado. Use as setas para navegar e F para tela cheia.

**Evento:** 6 de dezembro de 2026, domingo, das 8h às 12h.

**Local:** Instituto Pedro Arantes, R. Pedro Arantes - Alto da Boa Vista, Três Lagoas - MS, 79640-500.

**Página:** https://agenciaothon.github.io/torneio-do-bem-apresentacao/

## Arquivo

`index.html` contém o HTML, os estilos, as animações e as imagens incorporadas. A tipografia utiliza o Google Fonts.

A publicação utiliza GitHub Pages a partir da raiz da branch `main`.
